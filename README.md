# Voice AI Backend

This is the backend for a mobile AI wellness assistant app.

## Features
- AI chat responses using OpenAI
- Voice transcription (speech-to-text)
- Secure API backend for mobile app
- User memory system (optional upgrade)

## Built With
- Node.js
- Express
- OpenAI API

## Purpose
Power a mobile voice + chat AI assistant that helps users with emotional support and guidance.
